#  Pomodoro Pro — Focus & Productivity App

**A calming space to focus, one session at a time.**

Pomodoro Pro is an interactive productivity application built with Python and Streamlit. It helps users manage their focus sessions and breaks while creating a relaxing environment with music, nature sounds, and YouTube.

## 🚀 Live Demo

👉 **[Open Pomodoro Pro](https://pomodoroapp-majrisalma.streamlit.app/)**

Try the app directly in your browser — no installation required!

## ✨ Features

- ⏱️ **Pomodoro Timer** — Manage focus sessions and breaks.
- ☕ **Break Management** — Switch between short and long breaks.
- 🎵 **Music Collection** — Enjoy music while focusing.
- 🌿 **Nature Sounds** — Create a calm and relaxing workspace.
- ▶️ **YouTube Integration** — Play your preferred YouTube videos or playlists.
- 🎨 **Atmosphere Themes** — Customize the interface with different visual atmospheres.
- 📊 **Productivity Tracking** — Track completed focus sessions and productivity statistics.
- 🖥️ **Interactive Interface** — A clean and user-friendly design built with Streamlit.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## 🎯 Project Goal

The goal of Pomodoro Pro is to make focused work sessions more enjoyable by combining time management, relaxing sounds, and a customizable interface in one application.
